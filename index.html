Installing an unsigned beta
Windows: if SmartScreen appears, choose More info → Run anyway.
macOS: drag Flow to Applications, then Control-click the app and choose Open. If macOS still blocks it, use System Settings → Privacy & Security → Open Anyway.

Flow may also ask for microphone/accessibility permissions during voice testing. This page is intentionally marked noindex, but anyone with the link can download the beta.
